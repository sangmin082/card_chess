# App Store 심사 제출 가이드 — 카드 체스 5x5

모든 입력은 https://appstoreconnect.apple.com → 앱 → **카드 체스 5x5** 에서 한다.
아래 문구는 그대로 복사해 붙여 넣으면 된다.

- 새로 올리려면 GitHub → Actions → **iOS** → Run workflow (TestFlight 업로드 체크).

- 국가: 전체 또는 대한민국만. EU 를 포함하면 "디지털 서비스법(DSA) 거래자 상태" 를 물어본다.
  개인 취미 앱이면 **거래자가 아님** 을 선택한다.

## 4. 버전 페이지 (왼쪽 메뉴 "iOS 앱 → 1.0 제출 준비 중")

### 버전 번호
앱의 버전은 **1.0.0** 이다. 페이지 왼쪽 위 버전이 `1.0` 이면 **1.0.0** 으로 바꿔야 빌드를 선택할 수 있다.

### 스크린샷
"iPhone 6.9형 디스플레이" 칸에 `docs/appstore/screenshots-6.9/` 의 PNG 5장을 순서대로 끌어다 놓는다
(1320×2868). 다른 크기는 자동으로 축소되어 쓰인다. 이 앱은 iPhone 전용이라 iPad 스크린샷은 필요 없다.

### 프로모션 텍스트 (170자, 언제든 수정 가능)
```
카드 2장으로 말을 움직이는 새로운 체스. 내가 쓴 카드는 곧 상대의 손으로! 5분 튜토리얼로 바로 시작하세요.
```

### 설명
```
카드 체스는 5×5 보드에서 말 5개씩으로 겨루는 2인 전략 보드게임입니다.

말에는 정해진 이동 방식이 없습니다. 손에 든 카드 2장 중 하나를 골라, 그 카드의 규칙대로 말을 움직입니다. 쓴 카드는 대기 존을 거쳐 상대 손으로 넘어가기 때문에, 어떤 카드를 쓰느냐가 곧 상대에게 무엇을 넘겨주느냐가 됩니다.

■ 게임 방법
• 카드 5장: 룩, 비숍, 어태커, 나이트, 점퍼
• 말은 앞을 바라보고 있고, 어태커는 바라보는 방향으로만 나아갑니다. 끝 줄에 닿으면 방향이 바뀝니다.
• 점퍼는 옆에 있는 내 말을 뛰어넘어야만 움직입니다. 보드에 말이 둘만 남으면 퀸으로 바뀝니다.
• 상대 말을 모두 잡거나, 상대 성을 차지하고 한 턴을 버티면 승리
• 3세트 중 2세트를 먼저 이기면 최종 승리. 후공은 카드를 나눠 주는 권한을 가집니다.

■ 주요 기능
• 튜토리얼: 보드에서 직접 말을 움직이며 5분 만에 규칙을 배웁니다.
• AI 대전: 쉬움 · 보통 · 어려움 3단계. 막힐 땐 AI 힌트로 추천 수를 확인하세요.
• 로컬 2인 대전: 한 기기로 친구와 번갈아 플레이
• 기보 자동 저장과 재생, 무르기, 기권
• 하우스룰 설정

광고와 로그인이 없고, 인터넷 연결 없이 플레이할 수 있습니다.
```

### 키워드 (100자)

## 5. 연령 등급 설문

모든 질문에 **없음 / 아니요** 로 답한다.
(폭력, 성적 콘텐츠, 비속어, 약물, 공포, 도박, 의료 정보, 무제한 웹 접근, 사용자 생성 콘텐츠, 메시지, 광고 등 모두 해당 없음)
결과는 **4+** 로 나온다.

## 6. 제출

버전 페이지 오른쪽 위 **심사에 추가** → **심사를 위해 제출**.
심사는 보통 1~3일 걸린다. 결과는 이메일과 App Store Connect 앱으로 온다.
